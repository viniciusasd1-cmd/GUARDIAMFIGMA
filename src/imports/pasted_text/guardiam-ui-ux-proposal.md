GUARDIAM — ALTERNATIVA VISUAL 02: CLEAN, CLARA E PREMIUM

Crie uma NOVA proposta completa de UI/UX para o GUARDIAM, independente da versão dark criada anteriormente.

IMPORTANTE:
Não reutilize a estética dark, neon, cyberpunk ou futurista da proposta anterior.

Quero testar uma direção visual completamente diferente:
CLEAN + LIGHT + MINIMALISTA + PREMIUM + HUMANA + CONFIÁVEL.

O objetivo é descobrir se o GUARDIAM transmite mais segurança e confiança quando parece um produto de tecnologia premium, porém simples e discreto.

NÃO alterar ou inventar funcionalidades do produto.
O Figma deve representar somente UI, UX, layout, componentes, estados visuais e fluxo de navegação.

DIREÇÃO VISUAL

Usar uma interface predominantemente clara.

Preferência:
- fundo branco ou off-white;
- superfícies muito claras;
- cinza suave;
- azul profundo como cor institucional;
- verde discreto para proteção ativa;
- vermelho controlado para SOS;
- amarelo suave para atenção.

Evitar:
- neon;
- glow;
- excesso de gradientes;
- fundos pretos;
- efeitos futuristas;
- excesso de sombras;
- bordas exageradas;
- aparência de videogame;
- excesso de elementos decorativos.

A interface deve parecer:
confiável, moderna, elegante, simples e madura.

REFERÊNCIA DE SENSAÇÃO

Imagine um produto de segurança digital premium desenvolvido para o mercado internacional.

Deve transmitir confiança antes de transmitir tecnologia.

A pessoa deve olhar para a tela e pensar:
“É simples. Eu entendo. Posso confiar.”
